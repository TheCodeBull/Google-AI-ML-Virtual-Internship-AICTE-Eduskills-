Virtual Internship: AICTE-EdusSkills Internship & Learning Program backed by GoogleForDevelopers(GFD) -

This repository contains the code, notebooks, and projects I completed during my virtual internship, based on the Google for Developers Learning Pathways. The work covers object detection, image classification, and visual product search using TensorFlow and on-device machine learning.

About

The goal of this internship was to build practical skills in computer vision: training custom models, converting them for mobile use, and integrating them into apps. Each folder in this repo maps to one learning module and contains my code and notes.

Learning Modules
#	Module
1	TensorFlow computer vision:	Intro to computer vision with TensorFlow 2
2	Get started with object detection: Training and running a custom object detection model	
3	Go further with object detection:	Improving and customizing detection models
4	Get started with image product search:	Building a visual product search experience	
5	Go further with image product search:	Extending product search with custom models	
6	Go further with image classification:	Training and tuning image classifiers	
7	TensorFlow computer vision codelab	Intro to computer vision with TensorFlow 2
